## ✨ Deploy in 1 minuut - GEEN CONFIG NODIG!

### 🎯 **Stap 1: Klik & Deploy**
**[👉 DEPLOY NU](https://vercel.com/new/clone?repository-url=https://github.com/Albinht/order-export-pro&env=DATABASE_URL&envDescription=Just%20add%20this%20one%20variable&envExample=DATABASE_URL=file:./prisma/database.db)**

### 📝 **Stap 2: Environment Variable**
Wanneer Vercel vraagt om environment variables, vul **ALLEEN** dit in:
```
DATABASE_URL=file:./prisma/database.db
```

### ✅ **Stap 3: Klaar!**
- Klik **"Deploy"**
- Wacht 2 minuten
- Open je app!

## 🎉 **Eerste keer setup (IN DE APP!)**

1. **Open je app:** `https://[jouw-naam].vercel.app`
2. **Je komt automatisch op de Setup pagina**
3. **Vul je store gegevens in:**
   - Kies Shopify of WooCommerce
   - Store domain
   - API token
4. **Klik "Complete Setup"**
5. **Login met:**
   - Username: `admin`
   - Password: `1n$$2O%n2$f2`
